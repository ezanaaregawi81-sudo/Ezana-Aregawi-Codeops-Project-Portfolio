# Habesha Eatery Mini-Site

An accessible, semantic HTML5 two-page website built for a fictional restaurant named "Habesha Eatery" located in Bole, Addis Ababa.

## How to Open the Site
1. Clone or download this repository onto your machine.
2. Navigate to your project root folder containing `index.html` and `contact.html`.
3. Double-click `index.html` to launch the site in your preferred modern web browser, or serve it using an extension like Live Server in VS Code.
4. Use the navigation links at the top to seamlessly toggle between the **Reservations** and **Contact** pages.
